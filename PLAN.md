# План продукту «Поруч»

## Щоденний сценарій

| Етап | Що робить людина | Що дає застосунок |
| --- | --- | --- |
| Налаштування | Створює профіль і вибирає цілі | Формує список вправ без повторів за вибраними цілями |
| Практика | Відкриває наступне заняття | Показує кроки, критерій успіху та спосіб спростити вправу |
| Результат | Записує оцінку та коротку нотатку | Оновлює журнал і пріоритет наступного заняття |
| Короткі виходи | Спостерігає за собакою й заповнює результат | Зберігає тривалість та реакції. Після складної спроби пропонує менше часу або легший рух до дверей |
| Прогрес | Переглядає останній тиждень і робить резервну копію | Показує активність за днями, завершені вправи й надає експорт та імпорт |

## Програма для собаки, яка шкодить удома на самоті

1. У першу чергу фізично перекрити доступ до котячого лотка, проводів і речей, які можна проковтнути. Перевірити, що коти зберегли доступ до лотка.
2. Перевірити на відео реакції під час короткого виходу. Фіксувати перші зміни в поведінці, навіть якщо собака мовчить. Для довгих відлучень організувати догляд до появи стабільного комфорту.
3. Паралельно відпрацьовувати спокій на килимку, дозволене жування та короткі пошукові ігри за присутності людини.
4. Повторювати комфортну тривалість у подібних умовах. Підвищувати складність лише після кількох спокійних повторів. Журнал допомагає порівняти умови та реакції.

## Реалізація

- Статична PWA на HTML, CSS і JavaScript. Зовнішні API та збірка відсутні.
- Бібліотека з 17 вправ. Пошук, категорії й клікер доступні з бібліотеки.
- Локальний профіль і журнал. Резервна копія JSON з перевіркою формату та явним підтвердженням відновлення.
- Service worker кешує інтерфейс, навчальні матеріали й зображення. Маніфест визначає встановлення та стартову адресу відносно репозиторію.
- Публікація з гілки `main` через GitHub Pages.

## Критерії приймання

- Зміна цілей перебудовує план. Успішне заняття оновлює прогрес.
- Пошук і категорії знаходять потрібну вправу.
- Таймер показує час від початку, зберігає фактичну тривалість. Під час фіксації неспокою наступна порада спрощує спробу.
- Імпорт коректної копії відновлює дані. Пошкоджений файл залишає поточні дані у сховищі.
- Після завантаження в мережі вправи та журнал доступні офлайн. Усі ресурси відкриваються з підшляху `/dogs/`.
