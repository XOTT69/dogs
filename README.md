# Поруч

Українськомовна PWA для домашніх тренувань із собакою. 17 вправ із винагородою, персональний порядок занять, таймер коротких виходів, журнал, тижнева статистика, клікер і резервна копія. Усі можливості доступні без реєстрації, реклами, підписки й платного API.

## Як почати

1. У профілі додайте ім’я собаки й оберіть цілі. Для собаки, яка гризе речі на самоті, можна почати із цілей «Спокій на самоті», «Гризіння речей» і «Котячий лоток».
2. На головному екрані відкрийте наступне заняття. Після виконання збережіть результат і короткі спостереження.
3. Коли практикуєте короткі виходи, відкрийте «Самотність». За можливості спостерігайте через камеру й поверніться при перших ознаках неспокою. У журналі можна вказати фактичний час і помічені реакції.
4. Коли переносите дані на інший пристрій, експортуйте резервну копію у профілі та імпортуйте її на новому пристрої. Імпорт замінює профіль та журнал після підтвердження.

На iPhone відкрийте застосунок у Safari та виберіть «Поділитися» → «На початковий екран». Для офлайн-роботи спочатку відкрийте застосунок з інтернетом. Якщо Safari і встановлений застосунок мають окремі дані, скористайтеся експортом та імпортом.

## GitHub Pages

У репозиторії відкрийте **Settings → Pages**, виберіть **Deploy from a branch**, гілку **main** і папку **/ (root)**, тоді натисніть **Save**. Сторінка збирається автоматично і буде доступна за адресою [xott69.github.io/dogs/](https://xott69.github.io/dogs/). Файли мають відносні шляхи, а `.nojekyll` дозволяє роздавати їх напряму. Окремий workflow і секрети не потрібні.

Для локальної перевірки в корені репозиторію виконайте `python3 -m http.server 8000` і відкрийте [localhost:8000](http://localhost:8000). Після зміни файлів застосунку збільшіть версію кешу у `sw.js`. Новий service worker активується, коли закриті старі вкладки з PWA.
